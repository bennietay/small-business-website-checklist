# Contributing

Please suggest changes that make the checklist more accurate or easier for a small business owner to use.

- Explain the practical problem the change addresses.
- Prefer plain language and actions that can be verified.
- Do not add unsupported statistics, legal claims, fabricated reviews, awards, or credentials.
- Keep vendor recommendations optional and disclose any commercial relationship.
- Do not add tracking, scripts, or external dependencies to the checklist.

Small corrections can be proposed as a pull request. Bennie Studio reviews changes before merging them.
