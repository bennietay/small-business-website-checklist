# Small Business Website Launch Checklist

A practical, reusable checklist for planning, testing, and launching a small business website. It covers customer goals, content, mobile use, search foundations, performance, accessibility, enquiry paths, launch safety, and the first month after launch.

This checklist is published as a public resource by Bennie Studio. For the Malaysia-focused web version and more context, see the [Small Business Website Launch Checklist for Malaysia](https://bennietay.com/malaysia-small-business-website-launch-checklist/).

## Use the checklist

Open [`CHECKLIST.md`](CHECKLIST.md), copy it into your project notes, and assign an owner and completion date to each section. Mark an item complete only after checking the staging or live site. Record deferred work with an owner and date.
